# Code of conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

## Expected behavior

- Discuss code, not people. "This breaks when the config is empty" is actionable;
  "this is unprofessional work" is not.
- Disagreement is welcome and expected. Contempt is not.
- No harassment, personal attacks, unwelcome attention, or discrimination in issues,
  pull requests, discussions, or anywhere else this project's name appears.

## Enforcement

Report behavior that violates this code of conduct to the maintainer through
[GitHub](https://github.com/gjoliveira9634). All reports are confidential.
Responses are proportionate to the severity and will be applied consistently.
