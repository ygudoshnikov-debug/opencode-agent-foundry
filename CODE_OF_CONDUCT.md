# Code of conduct

## The short version

Be decent. Assume the person on the other end is trying to build something and having a hard day.

## The longer version

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In practice that means:

- Criticise code, not people. "This breaks when the config is empty" is useful; "this is amateur
  work" is not.
- Disagreement is fine and expected. Contempt is not.
- No harassment, no personal attacks, no unwelcome attention, in issues, pull requests or anywhere
  else carrying this project's name.

## Enforcement

Report anything that crosses the line to the maintainer through
[GitHub](https://github.com/gjoliveira9634). Reports stay private. Responses range from a request to
edit a comment through to a permanent ban, proportionate to what happened and whether it repeats.
