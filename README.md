# 🏭 opencode-agent-foundry - Your AI Team, Working for You

## 🚀 What Is This?

Welcome! This software helps you manage multiple AI assistants at once. Instead of using one AI that tries to do everything, **opencode-agent-foundry** organizes a whole team of specialized AI workers. Each worker has a specific job, like writing code, checking for errors, or planning tasks. It’s like having a project manager, developers, and quality checkers—all powered by AI—working together on your computer.

Think of it as a smart factory for your projects. The "foundry" creates and manages AI agents that build things for you. You stay in control, but the heavy lifting is done automatically.

## 🎯 Who Is This For?

This is for anyone who wants to use AI to get work done faster—without needing to be a programmer. If you can use a web browser and download files, you can use this tool. It’s especially helpful for:

- **Freelancers** juggling multiple client projects
- **Students** writing reports or coding assignments
- **Small business owners** automating repetitive tasks
- **Curious users** who want to see what AI can really do

## ✨ Key Features

Here’s what makes this tool special:

### 🧠 Hierarchical Agent Orchestration
Your AI team is organized like a real company. A "manager" agent plans the work, assigns tasks to "specialist" agents, and checks their results. This means bigger, more complex projects get done correctly.

### 🎯 Specialized Roles at Every Scope
Each AI agent has a specific role. One might be great at writing Python code, another at explaining concepts, and another at finding bugs. You don’t need one AI to do everything—you get the right tool for each job.

### 💰 Budgeted Context
AI has limits on how much information it can remember at once. This tool smartly manages that "memory budget," so your AI agents don’t get confused or lose track of important details.

### 🏗️ Parallel Builders
Multiple AI agents can work on different parts of a project at the same time. This dramatically speeds up your workflow.

### ✅ Evidence-Gated Completion
The system doesn’t just trust the AI when it says "I’m done." It checks the actual results against evidence and proof before marking a task as complete. This reduces errors and improves quality.

### 🖥️ Native Desktop Console
You get a clean, easy-to-use desktop application (not just a command-line tool). You can see your AI team’s progress on a visual board, like a digital kanban board.

## 📖 How to Use the App

### The Main Dashboard

When you open the app, you’ll see a clean dashboard. It shows:

- **Your Projects** – A list of all your workspaces
- **Agent Status** – Which AI workers are active, idle, or busy
- **Task Board** – A visual board showing tasks in different stages (To Do, In Progress, Done)

### Creating a Project

1. Click **"New Project"**
2. Give your project a name (e.g., "Website Redesign")
3. Choose a template or start from scratch
4. Click **"Create"**

### Adding Tasks

Inside a project, click **"Add Task"** to create a new job for your AI team. You can:

- Write a description of what you need
- Assign it to a specific agent role (e.g., "Code Writer," "Reviewer")
- Set a priority level

### Watching Your Team Work

The task board updates in real time. You’ll see tasks move from "To Do" to "In Progress" as agents pick them up. When they finish, tasks move to "Done" with a checkmark showing the evidence was verified.

### Managing Settings

Click the gear icon in the top-right corner to access settings. Here you can:

- Adjust how many agents work at once
- Set your AI provider preferences
- Change the interface theme (light or dark mode)

## 🧪 Troubleshooting Common Issues

### The App Won’t Start

- Make sure you have enough free memory (close other programs)
- Check that your internet connection is active
- Try restarting your computer, then launch the app again

### Tasks Are Stuck

- Check your internet connection
- Look at the agent status—are they all busy?
- Try pausing and resuming the task from the board

### I Can’t Find Downloaded Files

- Open your "Downloads" folder (usually in File Explorer)
- Look for a file named "opencode-agent-foundry" or similar
- If you’re unsure, search your computer for "opencode-agent-foundry"
